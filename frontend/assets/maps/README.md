# Rwanda District Boundaries

`rwanda-districts.geojson` is the simplified Rwanda ADM2 dataset from geoBoundaries gbOpen.

- Boundary ID: RWA-ADM2-39286606
- Original source: Open Data Rwanda
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Attribution: geoBoundaries / Open Data Rwanda
- Metadata: https://www.geoboundaries.org/api/current/gbOpen/RWA/ADM2/
- Pinned source: https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/9469f09/releaseData/gbOpen/RWA/ADM2/geoBoundaries-RWA-ADM2_simplified.geojson

The map uses district outlines, not a representation of exact survey boundaries.

Turf.js 7.2.0 is bundled under `frontend/vendor/turf/` with its MIT license.
